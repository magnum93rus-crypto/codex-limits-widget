# Codex Limits

Прозрачный индикатор лимитов Codex для Windows. Показывает остаток и время до сброса в свободной части строки ввода между разрешениями и моделью.

## Возможности

- Остаток лимита аккаунта и обратный отсчёт до сброса.
- Подробности по нажатию: окна лимитов, точное время сброса в Москве, кредиты и доступные полные сбросы.
- Обновление раз в минуту и ручное обновление.
- Прозрачный фон, жирный Segoe UI, автоматическая привязка к интерфейсу.
- Подстройка при изменении масштаба, размеров и положения окна Codex.
- Скрытие при диктовке, сворачивании и переключении в другое приложение.
- Повторный поиск элементов после перестройки интерфейса без исчезновения при кратковременных сбоях.
- Перетаскивание, контекстное меню и значок в трее.

Это отдельная локальная утилита поверх окна Codex. Она использует Windows UI Automation для размещения и сохраняет установленное приложение исходным. Утилита не связана с OpenAI официально.

## Требования и запуск

Проверенная платформа: Windows 11 x64, .NET Framework 4.8, установленный настольный Codex с доступным codex.exe и выполненным входом в ChatGPT.

Скачайте CodexLimits.exe из Releases, поместите в папку с доступом на запись и запустите. Откройте Codex: индикатор появится рядом с разрешениями и моделью.

- Нажатие на текст открывает подробности.
- Перетаскивание текста настраивает положение.
- Правый щелчок по тексту или значку в трее открывает меню. «Вернуть положение» отменяет смещение; «Выход» завершает утилиту.
- Повторный запуск работающего экземпляра открывает подробности.

Настройки и техническое состояние сохраняются в подпапке work рядом с исполняемым файлом. При запуске из исходной рабочей структуры автоматически используется существующая папка runtime проекта. Автозапуск Windows по умолчанию выключен.

## Данные и поведение

Источник — метод [account/rateLimits/read](https://learn.chatgpt.com/docs/app-server) установленного Codex CLI через локальный stdio. Авторизацию обслуживает Codex CLI.

Остаток вычисляется как 100 минус usedPercent в пределах 0–100; период определяется по windowDurationMins. В строке показывается наиболее ограничивающее из доступных окон общего лимита Codex. Лимиты относятся ко всему аккаунту и всем чатам.

Непредоставленные значения обозначаются прочерком. При потере соединения последние данные помечаются знаком ~; обновление возобновляется автоматически. Истёкший таймер сам по себе не увеличивает остаток. Кредиты показываются в единицах сервиса; полные сбросы отображаются справочно.

Явные кнопки остановки и отмены диктовки немедленно скрывают индикатор. При кратковременной перестройке интерфейса последняя подтверждённая позиция сохраняется до одной секунды с повторным поиском элементов. При устойчивом исчезновении обычной строки индикатор скрывается.

Размер рассчитывается по фактической высоте выбора модели и учитывает масштаб интерфейса и монитора. Окно подробностей также перестраивается. Изменение структуры доступности Codex в будущей версии может потребовать обновления привязки.

## Сборка

Откройте PowerShell в папке репозитория:

    .\test.ps1
    .\build.ps1
    .\dist\CodexLimits.exe

Компилятор берётся из установленного .NET Framework; пакеты не скачиваются. Для другой папки результата:

    .\build.ps1 -OutputDirectory '.\output'

Перед пересборкой работающего файла завершите экземпляр через меню или командой CodexLimits.exe --quit.

Проверки охватывают расчёты, неизвестные значения, таймеры, размещение, диктовку, масштаб, фокус и восстановление привязки.

Диагностика: --probe <json>, --diagnose <json>, --render <png> --fixture <json> --scale 1.5. Рендер использует переданный локальный набор данных; диагностические режимы не создают дополнительных постоянных экземпляров.
