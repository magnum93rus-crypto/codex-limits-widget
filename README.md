# Codex Limits

Локальный прозрачный индикатор лимитов для Windows. Размещается в строке Codex между разрешениями и выбором модели. Показывает процент остатка и обратный отсчёт до сброса. Размер и положение зависят от текущей геометрии интерфейса.

## Запуск и управление

Откройте `CodexLimits.exe`. Уже запущенный экземпляр откроет подробности при повторном запуске.

- Нажатие на текст индикатора открывает подробности: окна лимитов, точное время сброса в Москве, кредиты, число полных сбросов и время последнего обновления.
- Текст можно перетаскивать мышью. «Вернуть положение» в контекстном меню отменяет смещение.
- Правый щелчок по тексту или значку в трее открывает меню. «Выход» завершает приложение.
- Данные автоматически обновляются раз в 60 секунд. «Обновить» запрашивает их сразу.
- Значок в трее остаётся доступным, когда основное окно Codex свёрнуто или неактивно.

## Диктовка, масштаб и внешний вид

У индикатора прозрачный фон с попиксельным альфа-каналом. Семейство Segoe UI соответствует стандартному семейству интерфейса установленного Codex; для текста индикатора используется жирное начертание Bold.

Показ и скрытие выполняются без активации окна индикатора. Его собственное окно учитывается при проверке фокуса, чтобы исключить цикл появления и исчезновения. Неизменившийся текст повторно не перерисовывается.

При исчезновении обычной строки с разрешениями и моделью индикатор скрывается. Это охватывает замену строки панелью диктовки. Дополнительно распознаются явные кнопки остановки и отмены записи на русском и английском языках. После возвращения обычных элементов индикатор появляется автоматически. Автоматического плавающего размещения нет.

Каждую четверть секунды перепроверяется геометрия найденных элементов; полное обнаружение строки выполняется раз в секунду. Размер рассчитывается по фактической высоте выбора модели, поэтому учитывает масштаб интерфейса Codex и масштаб монитора. Окно подробностей также перестраивается при изменении масштаба. Если свободного места слишком мало, индикатор скрывается.

Это отдельное локальное окно поверх интерфейса. Файлы установленного Codex остаются исходными. Изменение структуры интерфейса в будущей версии приложения может потребовать обновления поиска элементов.

## Данные

Источник — установленный `codex.exe`, метод [`account/rateLimits/read`](https://learn.chatgpt.com/docs/app-server) через локальный stdio. Приложение использует вход, который обслуживает сам Codex. В коде клиента предусмотрены только инициализация и чтение лимитов.

Остаток вычисляется как `100 − usedPercent` в пределах 0–100. Период подписывается по `windowDurationMins`. В основной строке показывается наиболее ограничивающее из доступных окон общего лимита Codex. Лимиты относятся ко всему аккаунту и всем чатам. Непредоставленные значения обозначаются прочерком. При потере соединения последние значения помечаются `~`; обновление возобновляется автоматически. Истёкший таймер сам по себе не увеличивает процент остатка.

Кредиты показываются в единицах, возвращаемых сервисом. Полные сбросы отображаются справочно. Приложение их не расходует.

Настройки положения и техническое состояние сохраняются в `D:\AI проекты\улучшайзеры CODEX\work\codex-limits-widget\runtime`. При переносе одного исполняемого файла в другую папку используется подпапка `work` рядом с ним. Автозапуск Windows по умолчанию не настраивается.

## Сборка и проверки

Исходники находятся в `D:\AI проекты\улучшайзеры CODEX\work\codex-limits-widget`. Сборка использует установленный .NET Framework и не требует установки пакетов.

Из этой папки:

```powershell
.\test.ps1
.\build.ps1
```

Перед пересборкой завершите работающий экземпляр через меню «Выход» либо командой:

```powershell
& 'D:\AI проекты\улучшайзеры CODEX\outputs\codex-limits-widget\CodexLimits.exe' --quit
```

Диагностические режимы: `--probe <json>`, `--diagnose <json>`, `--render <png> --fixture <json> --scale 1.5`. Режимы диагностики не создают дополнительные постоянные экземпляры приложения.
