# Codex Limits 1.0.0

Первый публичный выпуск локального индикатора лимитов Codex для Windows x64.

- Прозрачный индикатор остатка и времени до сброса.
- Подробности с окнами лимитов, кредитами и доступными полными сбросами.
- Обновление раз в минуту.
- Скрытие при диктовке и подстройка под масштаб интерфейса.
- Исправлен цикл мигания из-за фокуса собственного окна.
- Добавлено повторное обнаружение элементов после перестройки интерфейса и сохранение подтверждённой позиции на время кратковременного сбоя.
- Поиск привязки ограничен строкой ввода и выполняется одним потоком, без копирования всех сообщений чата.
- Устранён рост памяти при длительной работе: системные объекты UI Automation освобождаются явно. Ускоренная проверка 12 000 обращений сохраняет расход памяти после прогрева около 28 МиБ в диагностическом процессе.
- Служебный app-server завершается после получения лимитов и после ошибок, освобождая память между обновлениями.
- Переключение в другое приложение сохраняет индикатор в окне Codex; другие приложения перекрывают его обычным образом.
- 36 проверок модели и размещения, а также проверка завершения служебного процесса после успешного, повторного и ошибочного запросов. Сборка выполняется с предупреждениями как ошибками.

Требуется установленный Codex с выполненным входом. Проверено в Windows 11 x64 с .NET Framework 4.8.
