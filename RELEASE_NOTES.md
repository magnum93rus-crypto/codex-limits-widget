# Codex Limits 1.0.0

Первый публичный выпуск локального индикатора лимитов Codex для Windows x64.

- Прозрачный индикатор остатка и времени до сброса.
- Подробности с окнами лимитов, кредитами и доступными полными сбросами.
- Обновление раз в минуту.
- Скрытие при диктовке и подстройка под масштаб интерфейса.
- Исправлен цикл мигания из-за фокуса собственного окна.
- Добавлено повторное обнаружение элементов после перестройки интерфейса и сохранение подтверждённой позиции на время кратковременного сбоя.
- 35 автоматических проверок пройдены; сборка выполняется с предупреждениями как ошибками.

Требуется установленный Codex с выполненным входом. Проверено в Windows 11 x64 с .NET Framework 4.8.
